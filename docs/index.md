# Engine

A 2D multiplayer game engine written in C++20, with an **editor** to make
games and a **runtime** to play and ship them. Games are written in Lua and
laid out in scenes; nothing is compiled to make one. Every game is networked
from the start: up to four players on an authoritative server over UDP.

```mermaid
flowchart LR
    G[Game folder<br>game.json · scripts/ · scenes/ · assets/]
    E[editor] -- edit scenes --> G
    E -- Play --> R[engine-runtime]
    R -- loads --> G
    E -- Export --> X[your-game/<br>runtime + game files]
```

The repository ships one example, [R-Type](examples/r-type.md): a cooperative
shoot'em up made only of Lua scripts, scenes and assets.

## Quick start

```sh
export VCPKG_ROOT=~/vcpkg
cmake --preset release && cmake --build --preset release
./build/release/bin/editor examples/r-type      # then press Play
```

## Project status

| Piece | State |
|---|---|
| Engine | ECS, fixed-step loop, physics, pathfinding, Lua runtime, UDP networking with replication, Raylib graphics and audio plugins |
| Runtime | Solo, host, join and dedicated server modes for any game folder |
| Editor | Scenes, viewport (place, move, scale, rotate), inspector with prefab overrides, undo/redo, Play, Export, command palette, settings |
| Next | A launcher to create and open games, scene management buttons, an asset browser, script hot reload, a second example game |
